# Master Bibliography

*Corrections note (2026-10-16): verification corrections (V1 legal, V2 facts and figures, V3 donations and licensing) were applied to this file where a source URL was given. See `verification/CORRECTIONS-APPLIED.md` for each change and for what was not applied. No lawyer or tribal government has reviewed this file.*

A deduplicated list of every source named in the Sources sections of `docs/research/`, `docs/data/` and `docs/design/` (A1-A3, B1-B3, C1-C3, D1-D4, E1-E3, F1-F4, G1-G4). Nothing was added that the files do not name. Reading it: a source is listed once, with the files that cite it in brackets.

## How to read this

- **Grouping** (primary, government, academic, and so on) was done by the synthesis for browsing. **Tiers** are different: B2 labels each source P (primary), A (authoritative secondary) or T (tertiary or journalistic). B1 and B3 split sources into "primary and authoritative" vs "secondary and tertiary". Where a file gave a tier or caveat, it is repeated here as written. Where no file labeled a source, it says "not tiered by source file".
- "Seen" means a file says it fetched or searched the source. It does not mean every claim was checked.
- **Reachability flags.** `[snippet only]` = seen only as a search snippet. `[blocked]` = the file could not fetch it. `[summarized]` = read through a summarizing fetch tool, not as raw text. `[unrelated]` = the page served different content. These are repeated in section 8.
- The `source_url` columns in `seed-data/*.csv` (for example one Wikipedia or OSU URL per treaty row) are **not** reproduced here. Treat them as part of the bibliography.
- Verification reports in `verification/` (V1-V3) cite further URLs. Those are not merged into this list; see each report's own method and sources sections.
- URLs are reproduced as the originating file wrote them (including odd capitalization). A few appear in two forms in different files; both are given.

Abbreviations: RIT = Ratified Indian Treaty number; NARA = National Archives; OSU = Oklahoma State University; LII = Cornell Legal Information Institute.
