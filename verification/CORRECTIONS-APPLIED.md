# Corrections Applied (V1, V2, V3)

Written by the Corrections Agent on 2026-10-16. This file lists every change made to the seed CSVs, the crosswalks and the research Markdown on the basis of the three verification reports, then every correction that was **not** applied and why. **Nothing here has had legal review or tribal review.** The agent applied sourced corrections mechanically and conservatively; a person must still check them (see `00-VERIFICATION-SUMMARY.md`).

## 1. Rules followed

1. A correction was applied only when the verification report shows a source URL for the new value.
2. Where the report says could-not-verify or single-source, the value was **not** changed. The tag was kept or downgraded and, where useful, annotated. No tag was upgraded on a single secondary source.
3. Donation safety: `donation_url` is blank for every red-flag or hold row (ILTF, Seeding Sovereignty, wsdp.org, indiancanyon.org, kaipoma.org). Each has a `vetting_notes` entry explaining the hold. The Friends of the Cheyenne River Youth Project identifier is not listed anywhere outside the verification reports, the backups and the V3 CSV.
4. Where verifiers conflict with each other, or a verifier conflicts with its own source, the correction was not applied and is listed as **unresolved** in section 5.

## 3. Backups and how to compare

- `verification/originals/` holds the 11 original seed CSVs (`*.csv`), the original `build/` output, and `docs-snapshot/` (the original `docs/`, `README.md` and `crosswalks/`). Compare any file with `diff verification/originals/<name> <current path>`.
- The backups are byte-identical to the originals. **They therefore still contain the held donation URLs and the original organizations-seed text that named the Friends of CRYP identifier.** They are audit copies. Do not publish or build from `verification/originals/`.
- CSV edits were written with Python's `csv.writer` (CRLF line endings); an untouched file round-trips byte-identical. Every edited CSV was re-parsed: row and column counts match the originals in all 11 seed files, and every crosswalk has a consistent column count.
